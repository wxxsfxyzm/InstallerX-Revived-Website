# 近期更新

了解 InstallerX Revived 从 26.05 到 26.09 的主要改进。各项功能的详细使用方法请参阅对应指南。

::: tip 简化安装
联网版和离线版现已合并为一个 APK。
为兼容应用内更新，发布渠道的文件名仍会保留 `online`。
:::

- **联网控制：** 在 **设置 → 网络设置 → 允许联网** 中控制更新检查和网络下载安装。
- **网络源模式：** 完整下载是兼容性优先的默认模式；服务器支持 HTTP Range 和强 ETag 时，智能、低存储占用模式可以流式处理单 APK，但签名分析能力有限。
- **签名控制：** 支持应用签名分析、拆分包分析、签名详情，以及配置级的签名不匹配和未知签名拦截；在受支持的系统 SDK 上，还可以检测 Android 17 v3.2 签名和 ML-DSA 签名。
- **配置与授权：** 支持未知作用域（针对 OPPO/vivo 的某些系统行为设计）、智能授权后备顺序，以及需要谨慎启用的会话安装自动批准。
- **设置与记录：** 你可以随时开启或关闭操作记录，关闭时选择保留或删除已有记录，也可以单独控制记录指示器。开启后最多保留最近 100 条记录。你还可以备份和还原配置文件、作用域、应用设置及历史记录。还原会在校验备份后替换当前设置。
- **系统集成：** 由于修复安装器锁定实现，自动锁定安装器功能已移除。
- **已安装模块检测：** InstallerX 可以检测已安装的 Magisk、KernelSU 和 APatch 模块，并在安装新模块时比较版本。

参阅[安装指南](./installation.md)、[应用设置](./app-settings.md)、[用户配置文件](./profiles.md)、[实验室](./laboratory.md)和[系统集成](./system-integration.md)。
